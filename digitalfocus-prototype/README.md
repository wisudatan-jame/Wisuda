# เว็บไซต์ต้นแบบ Digital Focus

ต้นแบบเว็บไซต์ใหม่ของ บริษัท ดิจิตอลโฟกัส จำกัด ใช้ระบบดีไซน์แบบเดียวกับ jpark.co
หน้าโซลูชันนำเสนอแบบ securesentinelsolutions.co.th

> ไฟล์นี้เป็น **ต้นแบบ (prototype)** สำหรับตกลงหน้าตาและเนื้อหา
> เว็บจริงควรทำเป็นธีม WordPress โดยใช้โครงสร้าง สี และคอมโพเนนต์ชุดเดียวกัน
> ขั้นตอนทำหลังบ้านและขึ้นเว็บจริงอยู่ใน [`docs/BACKEND_GUIDE_TH.md`](docs/BACKEND_GUIDE_TH.md)

## เริ่มต้นใช้งาน

1. ติดตั้ง [Git](https://git-scm.com/) และ [VS Code](https://code.visualstudio.com/)
2. ติดตั้งส่วนขยาย **Live Server** ใน VS Code
3. Clone repo แล้วเปิดโฟลเดอร์ `digitalfocus-prototype`
4. คลิกขวาที่ `listed.html` แล้วเลือก **Open with Live Server**
   หน้าเว็บจะรีเฟรชเองทุกครั้งที่บันทึกไฟล์

ไม่ต้อง build และไม่ต้องติดตั้ง npm ไฟล์เป็น HTML, CSS และ JavaScript ธรรมดา

## โครงสร้างของ `listed.html`

ไฟล์เรียงจากบนลงล่างดังนี้

1. **`<style>`** คือ CSS ทั้งหมด
2. **`<header>`** คือโลโก้ เมนูหลัก ปุ่มนักลงทุนสัมพันธ์ ปุ่มเปลี่ยนภาษา TH / EN และเมนูมือถือ (`#mnav`)
3. **`<main>`** คือเนื้อหาทุกหน้า แต่ละส่วนเป็น `<section>`
4. **`<footer>`** ตามด้วยปุ่มแชทลอย (`#fchat`) และแบนเนอร์คุกกี้
5. **`<script>`** คือการสลับหน้า เมนูมือถือ แท็บโซลูชัน ฟอร์ม และแบนเนอร์คุกกี้

### ระบบหน้า (สำคัญที่สุด)

ทุกหน้าอยู่ในไฟล์เดียว การสลับหน้าทำงานด้วย hash ใน URL เช่น `listed.html#solutions`

- **`data-pages`** บน `<section>` บอกว่า section นี้แสดงในหน้าไหนบ้าง
  ใส่ได้หลายหน้าโดยคั่นด้วยช่องว่าง

  ```html
  <section class="sec" data-pages="home about">  <!-- แสดงทั้งหน้าแรกและหน้าเกี่ยวกับเรา -->
  ```

- **`data-only`** บน `<div>` ภายใน section ที่ใช้ร่วมกัน ใช้แสดงบางส่วนเฉพาะหน้าเดียว

  ```html
  <div data-only="home">...</div>   <!-- แสดงเฉพาะหน้าแรก -->
  ```

- **`PAGES`** ในสคริปต์ เก็บข้อความบนแถบหัวของแต่ละหน้า ได้แก่ breadcrumb หัวข้อ และคำโปรย

  ```js
  about:['เกี่ยวกับเรา','หัวข้อใหญ่','คำโปรยใต้หัวข้อ'],
  ```

- **`ALIAS`** ในสคริปต์ ใช้ลิงก์ไปยังส่วนย่อยของหน้า
  เช่น `#ir` จะเปิดหน้าติดต่อเรา แล้วเลื่อนลงไปที่ `id="ir"`

  ```js
  ir:['contact','ir'],
  ```

ถ้าลิงก์ `href="#ชื่อ"` ไม่มีชื่อนั้นใน `PAGES` หรือ `ALIAS` ลิงก์จะไม่ทำงาน

### หน้าที่มีอยู่

| hash | หน้า |

## สีและตัวอักษร

แก้ที่ตัวแปรใน `:root` ตอนต้นของ `<style>` ทีเดียว แล้วทั้งเว็บจะเปลี่ยนตาม
ห้ามใส่รหัสสีตรง ๆ ในแต่ละจุด

| ตัวแปร | ใช้กับ |
|---|---|
| `--navy-900` / `--navy-800` / `--navy-700` | พื้นหลังสีเข้ม หัวข้อ |
| `--accent` | ปุ่มหลัก ลิงก์ ไอคอน |
| `--cyan` | ตัวเน้นบนพื้นเข้ม |
| `--paper-2` | พื้นหลังโทนอ่อนของ section สลับ (`.tint`) |
| `--display` / `--body` | ฟอนต์หัวข้อ (Anuphan) และฟอนต์เนื้อหา (IBM Plex Sans Thai) |

สีแดง เขียว และน้ำเงินของ Digital Focus ใช้ **เฉพาะในโลโก้** ไม่ใช้ตกแต่งส่วนอื่น

## งานที่ทำบ่อย

### แก้ข้อความ

ค้นหาข้อความเดิมด้วย Ctrl+F แล้วแก้ตรงนั้น
ข้อความบนแถบหัวของแต่ละหน้าอยู่ใน `PAGES` ในสคริปต์

### เปลี่ยนรูป

1. วางไฟล์ใน `img/` ตั้งชื่อเป็นภาษาอังกฤษตัวเล็ก ใช้ `-` คั่นคำ เช่น `proj-hospital.jpg`
2. ย่อรูปก่อนใช้ กว้างไม่เกิน 1600px และขนาดไม่เกิน 300KB
3. ใส่ `alt` บรรยายรูปทุกครั้ง และใส่ `loading="lazy"` ยกเว้นรูปส่วนบนสุดของหน้า
4. ถ้าเป็นภาพจำลอง ให้ใส่ป้าย `<span class="cap">ภาพจำลอง</span>` ในกรอบรูปด้วย

### เพิ่มหน้าใหม่

1. เพิ่ม `<section class="sec" data-pages="ชื่อหน้า">` ใน `<main>`
2. เพิ่มบรรทัดใน `PAGES` ในสคริปต์
3. เพิ่มลิงก์ `<a href="#ชื่อหน้า">` ใน `.nav`, `.mnav` และ footer
4. ถ้าต้องการให้แถบ CTA ท้ายหน้าแสดงในหน้าใหม่ ให้เพิ่มชื่อหน้าใน `data-pages` ของ section CTA

### เพิ่มอุตสาหกรรมในหน้าโซลูชัน

ต้องเพิ่ม 3 จุดให้ตรงกัน

1. ปุ่มแท็บ `.vtab` ใน `.vtabs` (ตั้ง `data-v="ชื่อ"` และ `id="vt-ชื่อ"`)
2. แผง `.vpanel` (ตั้ง `id="vp-ชื่อ"` และใส่ `hidden`) พร้อมรูป คำอธิบาย และ `.node` ของแต่ละระบบ
3. การ์ด `.sector` ในหน้าแรก (ตั้ง `data-sector="ชื่อ"`)

### เพิ่มหรือแก้ช่องทางออนไลน์

แก้ที่ตัวแปร `CH` ในสคริปต์ที่เดียว แล้วการ์ดในหน้าติดต่อเราและไอคอนใน footer จะเปลี่ยนตาม

ปุ่มแชทลอยมุมขวาล่าง (LINE, Facebook Messenger, โทร, อีเมล) เป็น HTML ใน `#fchatList` ต้องแก้แยกจาก `CH`

### แก้เนื้อหาทั้งสองภาษา

`listed.html` กับ `listed-en.html` เป็นไฟล์แยกกัน แก้ไฟล์หนึ่งแล้ว**ต้องแก้อีกไฟล์ให้ตรงกันเสมอ**
โครงสร้าง class และ id ต้องเหมือนกันทุกจุด เปลี่ยนแค่ข้อความ
คำเฉพาะในภาษาอังกฤษ: ใช้ **AiIOT** (ไม่ใช่ AIoT), "end-to-end Smart Security Solutions & AiIOT" และ "Thailand's first authorized Hikvision distributor"

## ขั้นตอนส่งงาน

1. สร้าง branch ใหม่ทุกครั้ง: `git checkout -b intern/ชื่องาน`
2. แก้ไข แล้วตรวจหน้าเว็บที่ความกว้าง **375px, 768px และ 1440px**
   ใช้ DevTools (F12) แล้วกด Toggle device toolbar
3. เปิด Console ใน DevTools แล้วตรวจว่าไม่มี error สีแดง
4. Commit เป็นงานละ commit และเขียนข้อความอธิบายว่าแก้อะไร
5. Push branch แล้วเปิด **Pull Request** ให้พี่เลี้ยงตรวจ
6. **ห้าม push เข้า `main` โดยตรง**

## ข้อมูลที่ต้องได้รับอนุมัติก่อนแก้

ข้อมูลเหล่านี้กระทบความน่าเชื่อถือของบริษัทที่เตรียมเข้าตลาดหลักทรัพย์ฯ
ห้ามแก้หรือเพิ่มเองโดยไม่มีเอกสารยืนยัน

- ตัวเลขสถิติและข้อมูลโครงการ เช่น จำนวนสาขา จำนวนกล้อง และปีที่ดำเนินการ
- ส่วนนักลงทุนสัมพันธ์ (`#ir`) และข้อความเกี่ยวกับการเข้าจดทะเบียน
- ข้อความ PDPA ในฟอร์มและแบนเนอร์คุกกี้
- ชื่อและตำแหน่งผู้บริหาร รางวัล และมาตรฐานที่ได้รับรอง
- โลโก้และรูปของลูกค้าหรือแบรนด์พันธมิตร (ต้องมีสิทธิ์ใช้งาน)
