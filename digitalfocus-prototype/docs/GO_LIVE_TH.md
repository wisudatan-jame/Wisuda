# ขึ้นเว็บไซต์ใหม่แบบเร่งด่วน (1–2 วัน)

ธีม WordPress **DF Listed** สร้างเสร็จและทดสอบแล้ว น้องฝึกงานไม่ต้องเขียนโค้ดเพิ่ม ทำตามขั้นตอนด้านล่างได้เลย

- ไฟล์ติดตั้ง: [`wp-theme/df-listed.zip`](../wp-theme/df-listed.zip)
- โค้ดธีม: [`wp-theme/df-listed/`](../wp-theme/df-listed/)
- ข้อมูลอ้างอิงเพิ่มเติม: [`BACKEND_GUIDE_TH.md`](BACKEND_GUIDE_TH.md)

## ธีมนี้ทำอะไรให้แล้ว

- **ทุกหน้าตามต้นแบบ:** หน้าแรก เกี่ยวกับเรา ธุรกิจของเรา โซลูชัน ผลิตภัณฑ์ ผลงานและลูกค้า ความยั่งยืน ข่าวสาร ติดต่อเรา
- **ภาษาไทยที่ `/about/` และภาษาอังกฤษที่ `/en/about/`:** ปุ่ม TH / EN สลับไปหน้าคู่ของอีกภาษา
- **โทนสีแบบ B (น้ำเงินครามและแดง):** ตามที่ผู้บริหารเลือก ธีมตั้งไว้เป็นค่าเริ่มต้นแล้ว
- **ฟอร์มส่งข้อมูลจริง:** ฟอร์มสมัครพันธมิตรและฟอร์มรับข่าวนักลงทุน
  - ข้อมูลเก็บในเมนู **ผู้ติดต่อจากเว็บ** ในหลังบ้าน และส่งอีเมลแจ้ง
  - มีช่องยินยอม PDPA กันสแปม และจำกัดการส่งซ้ำ
- **ข่าวสาร:** ใช้ Posts ของ WordPress ข่าวเดิมบนเว็บจะแสดงต่อได้ทันที ข่าวที่ปักหมุด (Sticky) ขึ้นเป็นข่าวเด่น
- **ตั้งค่าในหน้าเดียว:** เบอร์โทร อีเมล LINE Messenger และลิงก์โซเชียล อยู่ใน Customize ทุกจุดบนเว็บเปลี่ยนตาม
- **ลิงก์เดิมไม่เสีย:** URL ของเว็บเดิม เช่น `/about-2/`, `/contact-2/`, `/solution/` พาไปหน้าใหม่อัตโนมัติ
- **เพิ่มเนื้อหาด้วยปุ่มเดียว:** ปุ่มสร้างหน้า เมนู และข่าวตัวอย่าง อยู่ที่ Appearance → ตั้งค่าเนื้อหาเริ่มต้น

ทดสอบแล้วบน WordPress 6.5 และ PHP 8.3 ทั้งหน้าจอคอมพิวเตอร์และมือถือ ฟอร์ม การสลับภาษา โทนสี และการ redirect

## วันที่ 1: ติดตั้งบน staging

1. **สำรองเว็บจริง** ทั้งไฟล์และฐานข้อมูล ใช้ระบบ backup ของ hosting หรือปลั๊กอิน UpdraftPlus
2. **สร้าง staging** คัดลอกเว็บจริงไปไว้ที่ subdomain เช่น `staging.digitalfocus.co.th`
   ถ้า hosting มีปุ่มสร้าง staging ให้ใช้ปุ่มนั้น ถ้าไม่มีใช้ปลั๊กอิน WP Staging
3. ที่ staging ไปที่ **Appearance → Themes → Add New → Upload Theme** แล้วอัปโหลด `df-listed.zip`
   ถ้าอัปโหลดไม่ผ่านเพราะไฟล์ใหญ่ (ประมาณ 6.5 MB) ให้แตกไฟล์แล้วอัปโหลดโฟลเดอร์ `df-listed` ผ่าน FTP ไปที่ `wp-content/themes/`
4. กด **Activate** ธีม DF Listed
5. ไปที่ **Appearance → ตั้งค่าเนื้อหาเริ่มต้น**
   - ติ๊ก "ย้ายหน้าเดิมที่ใช้ชื่อลิงก์เดียวกันไปเป็นฉบับร่าง"
   - กด **สร้างเนื้อหาเริ่มต้น**
   - หน้าเดิมที่ซ้ำกับหน้าใหม่จะกลายเป็นฉบับร่างชื่อ `-old` ไม่ได้ถูกลบ กู้คืนได้
6. ไปที่ **Appearance → Customize → Digital Focus**
   - **โทนสี:** ตั้งเป็นแบบ B ไว้แล้ว ไม่ต้องเปลี่ยน
   - **ข้อมูลติดต่อและปุ่มแชท:** ตรวจเบอร์โทร อีเมล LINE และ Messenger
   - **ฟอร์มและคุกกี้:** ใส่อีเมลที่รับใบสมัคร ถ้าใช้ปลั๊กอิน PDPA Thailand อยู่แล้ว ให้ปิดแบนเนอร์คุกกี้ของธีม
7. ไปที่ **Settings → General** แก้ Tagline เป็น
   `ผู้นำ Smart Security Solutions & AiIOT ครบวงจร`
   ข้อความเดิมที่ระบุ Jigami, Wulian, Max View, iHorn ต้องเอาออก
8. ไปที่ **Settings → Permalinks** แล้วกด Save หนึ่งครั้ง เพื่อให้ลิงก์ใหม่ทำงาน

## วันที่ 1: ตั้งค่าที่ต้องทำเพิ่ม

| เรื่อง | ทำอย่างไร |
|---|---|
| อีเมลจากฟอร์มต้องไม่ตกสแปม | ติดตั้ง **WP Mail SMTP** ตั้งให้ส่งผ่านอีเมลของโดเมน digitalfocus.co.th |
| ประเภทเนื้อหา `solutions` เดิม (CPT UI) | เปิด CPT UI → Edit Post Types → `solutions` ตั้ง **Has Archive = False** เพื่อไม่ให้ทับหน้า `/solutions/` ใหม่ |
| ภาษาไทยในหลังบ้านและรูปแบบวันที่ | Settings → General → Site Language เลือก ภาษาไทย |
| หน้าแรกของเว็บ | ธีมตั้งให้แล้ว ตรวจใน Settings → Reading ว่า Homepage คือ "หน้าแรก" และ Posts page คือ "ข่าวสาร" |
| เวอร์ชัน PHP | ถ้า hosting ยังเป็น PHP 7.4 ให้ขออัปเกรดเป็น 8.2 ขึ้นไป ธีมรองรับทั้งสองแบบ |

## วันที่ 2: ตรวจบน staging

- [ ] เปิดทุกหน้าทั้งภาษาไทยและอังกฤษ บนคอมพิวเตอร์และมือถือ
- [ ] กด TH / EN แล้วไปหน้าคู่ที่ถูกต้อง
- [ ] ส่งฟอร์มสมัครพันธมิตรและฟอร์มรับข่าวนักลงทุนอย่างละ 1 ครั้ง ตรวจว่าได้อีเมล และข้อมูลขึ้นในเมนู "ผู้ติดต่อจากเว็บ"
- [ ] ฟอร์มไม่ยอมส่งถ้าไม่ติ๊กยินยอม PDPA
- [ ] ปุ่มแชทลอยเปิด LINE, Messenger, โทร และอีเมลได้จริงจากมือถือ
- [ ] การ์ดอุตสาหกรรมในหน้าแรกกดแล้วเปิดแท็บที่ถูกต้องในหน้าโซลูชัน
- [ ] เปิด URL เดิม เช่น `/about-2/`, `/contact-2/`, `/solution/` แล้วถูกพาไปหน้าใหม่
- [ ] ข่าวเดิมบนเว็บแสดงในหน้าข่าวสาร ปักหมุดข่าวที่ต้องการให้เป็นข่าวเด่น
- [ ] ให้ผู้บริหารหรือฝ่ายการตลาดตรวจเนื้อหาและตัวเลขบน staging

## วันที่ 2: ขึ้นเว็บจริง

1. สำรองเว็บจริงอีกครั้ง
2. ทำขั้นตอน "วันที่ 1" ซ้ำบนเว็บจริง (อัปโหลดธีม เปิดใช้ สร้างเนื้อหา ตั้ง Customize)
   หรือใช้ปุ่ม Push to live ของ hosting ถ้ามี
3. ล้าง cache ของ LiteSpeed (LiteSpeed Cache → Purge All)
4. ตรวจตามรายการด้านบนอีกรอบบนเว็บจริง
5. ถ้ามีปัญหาร้ายแรง เปลี่ยนกลับเป็นธีมเดิมที่ Appearance → Themes หน้าเดิมทั้งหมดยังอยู่ในฉบับร่าง

## แก้เนื้อหาหลังขึ้นเว็บ

- **ข่าว:** Posts → Add New ใส่ Featured image ทุกข่าว
- **ข้อความในหน้า:** เปิดหน้านั้นใน Pages แต่ละส่วนของหน้าเป็นบล็อก Custom HTML แยกกัน แก้ข้อความในบล็อกได้เลย
  ห้ามลบชื่อ `class` หรือ `id` เพราะหน้าตาจะเพี้ยน
- **รูปในหน้า:** อัปโหลดรูปใหม่ใน Media แล้วคัดลอก URL ไปแทนในบล็อก
  รูปเดิมของธีมเขียนเป็น `{{img}}/ชื่อไฟล์.jpg`
- **ลิงก์ไปหน้าอื่น:** ใช้รูปแบบ `{{url:about}}` ธีมจะเปลี่ยนเป็นลิงก์ของภาษานั้นให้เอง
  ชื่อที่ใช้ได้คือ home, about, business, solutions, brands, projects, esg, news, contact
- **หัวหน้าเพจสีน้ำเงิน:** แก้ใน Custom Fields ของหน้านั้น `_df_hero_title` คือหัวข้อ และ `_df_hero_lead` คือคำโปรย
  ถ้าไม่เห็นช่องนี้ ให้เปิดใน Preferences → Panels → Custom fields
- **เมนู:** Appearance → Menus มี 4 ชุด คือเมนูหลักและเมนูมือถือ ภาษาละชุด

## ส่วนที่ยังทำต่อได้หลังขึ้นเว็บ

ไม่จำเป็นต้องทำก่อนขึ้นเว็บ

- ข่าวภาษาอังกฤษ (ตอนนี้หน้า News ภาษาอังกฤษเป็นข้อความคงที่ ส่วนข่าวภาษาไทยดึงจาก Posts)
- ตั้งชื่อและคำอธิบายของแต่ละหน้าสำหรับ Google ด้วยปลั๊กอิน SEO
- ปิดหรือลบปลั๊กอินที่หน้าใหม่ไม่ได้ใช้ หลังตรวจแล้วว่าไม่มีหน้าอื่นใช้อยู่
